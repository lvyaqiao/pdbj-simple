# 部署与维护

本文件说明本仓库与 Rime 实际部署之间的关系：哪些文件需要部署、哪些文件是运行时自动生成（不入库）、以及日常维护流程。

## 一、部署步骤

本仓库本身就是 Rime 的用户目录（Weasel 中为"用户文件夹"）。迁移到新机器时：

1. 克隆或复制本仓库内容（忽略运行时文件，见下节）
2. 将以下文件/目录放入 Rime 用户目录：

   - `pdbj.schema.yaml` —— 方案定义
   - `pdbj.dict.yaml`、`pdbj.word.dict.yaml`、`pdbj.char.dict.yaml`、`pdbj.cz.dict.yaml`、`pdbj.fuhao.dict.yaml` —— 词库
   - `symbols_pdbj.yaml` —— 符号库
   - `lua/` —— 全部 Lua 组件（assembly、preedit、calc、date 等）
   - `weasel.custom.yaml`、`default.custom.yaml` —— 方案配置

3. 在输入法托盘菜单中执行 **重新部署**，或命令 `RimeDeployer` 触发部署

部署后 `build/` 下的编译产物、`*.userdb` 与 `*.userdb.txt` 由引擎自动生成，无需也不应提交。

## 二、运行时文件（不入库）

以下文件由 Rime 在本机生成，`.gitignore` 已排除，克隆后无需手动创建：

| 文件/目录 | 说明 |
| --------- | ---- |
| `installation.yaml` | 安装信息（含随机 installation_id） |
| `user.yaml` | 用户配置状态（last_build_time 等） |
| `build/` | 部署编译产物 |
| `pdbj.userdb/` | 用户词库增量数据 |

若这些文件出现在 `git status` 中，说明它们被意外修改或缺少忽略规则，不要提交。

## 三、目录结构

| 路径 | 内容 |
| ---- | ---- |
| `doc/拼读简并-入门指南.md` | 使用指南（源文档） |
| `doc/拼读简并-入门指南.pdf` | 指南的 PDF 导出版（与 md 同源） |
| `doc/images/` | 指南插图 |
| `lua/pdbj/` | 输入方案 Lua 组件 |
| `test/` | Lua 单元测试 |
| `.github/workflows/test.yml` | CI 测试 |
| `拼读简并历史版本/` | 历史发行版 zip 快照（仅本地磁盘留存，不入库） |

## 四、测试

需要 Lua 5.4 环境（CI 使用 leafo/gh-actions-lua）：

```bash
lua test/test_common.lua
lua test/test_preedit.lua
lua test/test_convert.lua
```

或统一入口：

```bash
lua test/runner.lua
```

## 五、发布流程

1. 修改 `doc/拼读简并-入门指南.md` 后，导出同内容 PDF 至 `doc/`（旧 PDF 保留同目录即可覆盖）
2. 打包发行快照：将部署所需文件（见第一节第 2 步）打包为 zip，放入 `拼读简并历史版本/`，命名 `pdbj-simple<YYMMDD>.zip`
3. 历史 zip 仅本地留存、不随 git 分发；如需对外发布，上传至仓库 Release 页

## 六、本机专属文件

`weasel.custom.yaml` 属于方案级配置，随库跟踪；而 `installation.yaml`、`user.yaml` 是机器状态，切勿提交。若发现个人数据被提交，用 `git rm --cached` 移出跟踪并保持磁盘文件。
